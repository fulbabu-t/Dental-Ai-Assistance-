# 📘 LEARN.md — Dentwise

## 🦷 Project Overview

Dentwise is an AI-powered dental appointment platform built using Next.js, TypeScript, Tailwind CSS, Clerk authentication, PostgreSQL, and Vapi AI Voice Agent.

This project helped me understand how to build a modern full-stack SaaS application with authentication, booking systems, subscriptions, dashboards, and AI integrations.

---

# 🚀 What I Learned

During this project, I learned:

- Building full-stack applications using Next.js App Router
- Creating responsive UIs with Tailwind CSS
- Using TypeScript for scalable development
- Managing authentication using Clerk
- Database modeling with PostgreSQL and Prisma
- Implementing protected routes and admin dashboards
- Building appointment booking workflows
- Integrating AI Voice Agents using Vapi
- Sending emails with Resend
- Managing API state with TanStack Query
- Handling environment variables securely
- Structuring large-scale production-ready applications

---

# 🛠️ Challenges Faced

## Authentication & Protected Routes
Managing user authentication and secure dashboard access was challenging initially.

### Solution
- Used Clerk middleware
- Protected dashboard routes
- Implemented session management properly

---

## Database Relationships
Designing relationships between users, appointments, subscriptions, and services required careful schema planning.

### Solution
- Used Prisma relational models
- Added optimized database queries
- Structured clean relations

---

## AI Voice Agent Integration
Integrating the Vapi voice assistant required handling API communication and assistant configuration.

### Solution
- Used secure environment variables
- Configured assistant workflows properly
- Improved voice interaction handling

---

## Email Delivery Problems
Email verification and booking confirmation emails initially failed during testing.

### Solution
- Integrated Resend email service
- Improved email templates
- Fixed SMTP configuration issues
